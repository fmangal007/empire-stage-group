## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Vite writes the production site to `dist/`.

## Cloudflare deployment

```bash
npm run deploy
```

Cloudflare settings:

- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`
- Production branch: `main`
- Root directory: leave blank
